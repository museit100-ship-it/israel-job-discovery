# חיפוש משרות יומי בישראל

המאגר הזה מיועד לקוד האיסוף, לרשימת המקורות ולתוצאות שהופקו ממודעות פומביות. קובץ הדשבורד, גיבויים, החלטות, קורות חיים, הערות ונתוני מועמדות נשמרים מחוץ למאגר.

## הרצה

הסורק משתמש ב־Ruby ובמקורות הקבועים ב־`sources.json`. לפני פנייה למקור הראשון, הוא מבקש ממסד הנתונים לשריין הרצה לפי שעון ישראל. המכסה היא הרצה מתוזמנת אחת והרצה ידנית אחת לכל היותר ביום. השריון חוסם הרצות חופפות, גם סביב חצות. תוצאות כל מקור נשמרות ביומן `discovery_runs`. אם הסורק נעצר לפני דיווח הסיום, ניסיון השריון הבא מתעד את פקיעת ההרצה.

התזמון פעיל בענף `main` ב־18:00 באזור `Asia/Jerusalem`. הוא מריץ את הקוד ומעדכן את הפיד בענף `expanded-job-discovery`. מסד הנתונים מקבל הרצה מתוזמנת החל מ־18:00 ועד סוף אותו יום אם GitHub מעכב את ההפעלה. כדי למנוע חפיפה, ההפעלה הידנית חסומה בין 17:50 ל־18:01 ובזמן הרצה פעילה. הסורק נעצר אחרי עשר דקות, וכשל מתועד ביומן וב־Actions. אין ניסיון חוזר אוטומטי. `lastExecution` בפיד מבדיל בין סריקה שהושלמה, כשל וחסימה לפני תחילת הסריקה.

## היקף החיבור בפועל

31 הלוחות הם לוחות חברות: 21 Greenhouse, שישה Ashby וארבעה Lever. שלוש המערכות אינן תחליף לכל מקורות החיפוש שהתבקשו. LinkedIn, Glassdoor, Facebook (קבוצות ופוסטים), Manpower, Nisha, Ethosia, AllJobs, דרושים IL ו־GotFriends טרם חוברו לאיסוף אוטומטי. בדשבורד הם קישורים לחיפוש ידני בלבד. אין קליטת דואר ואין הרשמה להתראות. חיבור עתידי צריך מקור נתונים מתועד והרשאה מתאימה לתנאי המקור; אין לעקוף חסימות או להשתמש בשירות בתשלום ללא אישור.

תוצאות קודמות נשמרות ב־`jobs.json` כדי לשמר מזהים ותאריכי גילוי. כשמקור נכשל, הסורק שומר את תוצאותיו האחרונות. כשהמקור נטען בהצלחה ומודעה נעלמה ממנו, המודעה מסומנת כלא פעילה.

## חיבור הדשבורד

לאחר העלאת הקבצים למאגר ציבורי, יש להגדיר בשדה `content` של תג המטא `job-discovery-feed` בדשבורד המקומי את כתובת ה־HTTPS של `jobs.json` בענף ברירת המחדל ב־raw.githubusercontent.com. יש לבדוק טעינה בדפדפן עם הדשבורד פתוח כקובץ מקומי. בהיעדר חיבור, הדשבורד מציג את התוצאות ששולבו בקובץ. אחרי חיבור מוצלח, הדשבורד שומר עותק מקומי של הפיד לשימוש כשאין רשת.

## גיבוי ושחזור

בתיקיית `local-backup` שמחוץ למאגר שמורים קובץ ה־HTML המקורי וגיבוי ה־JSON שסופק לפני העדכון. כדי לשחזר את ממשק הדשבורד, יש להחזיר את ה־HTML המקורי לאותו נתיב. כדי לשחזר נתוני מעקב יש להשתמש בייבוא JSON מתוך הדשבורד רק לאחר ייצוא המצב העדכני, הייבוא ממזג רשומות ומשאיר עריכות קיימות. התאמות לא חד־משמעיות מוצגות לבדיקה ידנית. קבצי קורות חיים נשמרים ב־IndexedDB של הדפדפן. יש לשמור עותקים של הקבצים המקוריים בנפרד. גיבוי שנוצר בגרסה המעודכנת כולל גם החלטות סינון של הצעות.

## מקורות והתאמה

- [Greenhouse Job Board API](https://docs.greenhouse.io/job-board.html)
- [Ashby Job Posting API](https://developers.ashbyhq.com/docs/public-job-posting-api)

`sources.json` מגדיר את הלוחות, אתרי החברות ותיאורי הפעילות. תפקידים מסווגים לפי הכותרת או לפי תחומי אחריות שמופיעים במודעה. בתפקידי ניהול משרד נדרשת גם עדות לפעילות בתחום חוויית עובד, תקשורת או תוכן. משרות מסוננות לפי המיקום במודעה ומקבלות תוספת ניקוד באזור המרכז. הניקוד מעריך זיקה לתחום ולמיקום. את דרישות הסף והוותק בודקים במודעה. פרטים חסרים נשארים ריקים בפיד ומופיעים בדשבורד לפי המידע הזמין. נוסח תחומי האחריות והדרישות נלקח בקיצור מהמודעה כשהמבנה שלה מאפשר זאת.
