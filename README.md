# חיפוש משרות יומי בישראל

המאגר הזה מיועד לקוד האיסוף, לרשימת המקורות ולתוצאות שהופקו ממודעות פומביות. קובץ הדשבורד, גיבויים, החלטות, קורות חיים, הערות ונתוני מועמדות נשמרים מחוץ למאגר.

## הרצה

הסקריפט משתמש ב־Ruby ובספרייה הסטנדרטית. להרצה מקומית עם גישה לרשת יש להריץ `ruby discover.rb`. הקובץ `jobs.json` נכתב באופן אטומי ומכיל את מועד הניסיון האחרון, מועד החיפוש המוצלח האחרון, מצב המקורות ותוצאות החיפוש. מודעות קודמות נשמרות לצורך יציבות מזהים ותאריך גילוי. מודעה מסומנת כלא פעילה כאשר הפיד שלה נטען בהצלחה והיא כבר לא נמצאת בין התוצאות המתאימות. כשל במקור שומר את התוצאות האחרונות ממנו ומסמן את ההרצה ככושלת ב־Actions.

ההרצה המתוזמנת נקבעה ל־06:23 UTC מדי יום, 08:23 בחורף או 09:23 בקיץ בישראל. אפשר להפעיל אותה גם ידנית מהלשונית Actions. ההרצה הראשונה מופעלת גם בהעלאת הקוד והגדרת ה־workflow. אין צורך במפתח API, במסד נתונים או בשירות AI. התהליך משתמש ב־runner סטנדרטי של GitHub. מצב ההרצה והלוגים מופיעים ב־Actions, והודעות כשל תלויות בהגדרות ההתראות של החשבון.

## חיבור הדשבורד

לאחר העלאת הקבצים למאגר ציבורי, יש להגדיר בשדה `content` של תג המטא `job-discovery-feed` בדשבורד המקומי את כתובת ה־HTTPS של `jobs.json` בענף ברירת המחדל ב־raw.githubusercontent.com. יש לבדוק טעינה בדפדפן עם הדשבורד פתוח כקובץ מקומי. בהיעדר חיבור, הדשבורד מציג את התוצאות ששולבו בקובץ. אחרי חיבור מוצלח, הדשבורד שומר עותק מקומי של הפיד לשימוש כשאין רשת.

## גיבוי ושחזור

בתיקיית `local-backup` שמחוץ למאגר שמורים קובץ ה־HTML המקורי וגיבוי ה־JSON שסופק לפני העדכון. כדי לשחזר את ממשק הדשבורד, יש להחזיר את ה־HTML המקורי לאותו נתיב. כדי לשחזר נתוני מעקב יש להשתמש בייבוא JSON מתוך הדשבורד רק לאחר ייצוא המצב העדכני, משום שייבוא מחליף מועמדויות, משימות ושלבים. קבצי קורות חיים נשמרים ב־IndexedDB של הדפדפן. יש לשמור עותקים של הקבצים המקוריים בנפרד. גיבוי שנוצר בגרסה המעודכנת כולל גם החלטות סינון של הצעות.

## מקורות והתאמה

- [Greenhouse Job Board API](https://docs.greenhouse.io/job-board.html)
- [Ashby Job Posting API](https://developers.ashbyhq.com/docs/public-job-posting-api)

`sources.json` מגדיר את הלוחות, אתרי החברות ותיאורי הפעילות. תפקידים מסווגים לפי כותרת המשרה, מסוננים לפי המיקום שמופיע במודעה ומקבלים תוספת ניקוד באזור המרכז. התאמה אינה אימות דרישות או ותק. פרטים חסרים נשארים ריקים בפיד ומופיעים בדשבורד לפי המידע הזמין. נוסח תחומי האחריות והדרישות נלקח בקיצור מהמודעה כשהמבנה שלה מאפשר זאת.
